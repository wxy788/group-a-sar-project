## 二、方法（细节见 `src/autofocus/README.md`）

- **误差模型**：`D = ifft(fft(I0,[],2).*exp(+j·φ(f)))`，φ 定义在方位频谱上，与 PAFnet/SAR 自聚焦文献一致；
  补偿为 `ifft(fft(D).*exp(-j·φ̂))`。该模型可逆，故用幅度 NRMSE 度量恢复能力。
- **最小熵自聚焦（MEAF）**：相位基 = 偶次多项式 `u²,u⁴,u⁶` + cos/sin 各 4 阶（11 参数），
  以图像熵为目标先粗扫二次项、再 `fminsearch` 精调。
- **PGA**：能量最强 24 个距离单元 → 亮点圆移到 index 1 → 环绕升余弦窗（Na/4 逐轮收窄）→
  方位谱相位梯度 `Δφ(k)=angle(Σ X(k)conj(X(k−1)))` → **带内**累积 + **带内**去线性；带外保持边界常数；
  加「熵不劣化守卫」。

## 五、已知局限（如实记录）

1. **E8 失败**：真实 Level-0 上的高频随机误差（平滑宽 2 bin）超出「多项式 + 低阶正余弦」基的表达能力，
   MEAF 反而把 NRMSE 从 0.5287 抬到 0.6198。这类误差正是第 4 周起 PAFnet 学习型补偿的目标。
2. **熵与 NRMSE 不同向**：E8 的熵略降但 NRMSE 变差。真实杂波图（熵≈17.38，上限 18 bit）接近均匀分布，
   熵对散焦很不敏感 —— 因此**不能用熵单独作为验收指标**，必须与 NRMSE / 主瓣宽度并报。
3. **PGA 在分布杂波上无效**（B2/B3 全被守卫拒绝）：PGA 依赖孤立强散射体，这是方法固有前提。
   在这三张底图上它没有改善但也没有破坏（守卫生效），零误差输入下估计相位≈0。
4. **真实 SLC / Level-0 无绝对真值**：NRMSE 的分母是「注入误差前的同一块图像」，属于半仿真验证；
   真机数据只能靠熵/对比度/主瓣宽度与视觉判断，第 5–7 周补真实场景适配实验。
5. **MEAF 耗时 28.6 s 偏大**：11 参数 Nelder-Mead，每轮 2500 次评估。若要用于批量评估，
   可考虑降采样优化或在粗分辨率上先估相位。
