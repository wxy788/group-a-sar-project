## 一、任务背景

自聚焦处理由平台运动误差引入的**非线性方位相位误差**导致的散焦。本项目要求：选一种深度网络恢复散焦复数图像，并与传统 **PGA（Phase Gradient Autofocus）** 比较聚焦质量与推理耗时。训练/微调与独立测试在 Sentinel‑1 SM SLC 上完成。

## 二、候选方案对比

### 2.1 PAFnet（推荐首选）

- **文献**：[6] Zhi Liu, Shuyuan Yang, Quanwei Gao, Zhixi Feng, Min Wang, Licheng Jiao. *AFnet and PAFnet: Fast and Accurate SAR Autofocus Based on Deep Learning.* IEEE TGRS, 2022, vol. 60, pp. 1–13. DOI: 10.1109/TGRS.2022.3217063
- **核心思想**：非迭代、无监督的自聚焦方案；以**图像熵**作为损失函数，用 CNN 完成特征提取与相位参数估计。论文提出两个模型：
  - **AFnet**：端到端自聚焦网络；
  - **PAFnet（Progressive AFnet）**：**逐级（layer‑by‑layer）聚焦**，计算更高效，更适合课程项目。
- **网络结构要点（需核对原文图）**：编码器式 CNN 提取特征 → 回归相位误差系数（多项式）→ 在方位频谱上做「FFT → 相位补偿 → IFFT」实现可微补偿，逐级消除残余误差。
- **输入 / 输出**：
  - 输入：散焦**复数图像**（幅度+相位，或 I/Q 双通道）；
  - 输出：聚焦**复数图像**（同尺寸）；
  - 监督：无监督，损失 = 图像熵，**不需真值参考图**。
- **代码与依赖**：官方仓库 `github.com/aisari/AutofocusSAR`（含 PAFnet）。依赖 `torchbox`、`torchsar`（`pip install torchbox torchsar`）。训练示例：`python train.py --lr 1e-2 --num_epoch 1000 --device cuda:0`。
- **优点**：官方实现完整、上手快、无监督易构造训练样本，第 4 周跑通把握大。

### 2.2 RAFnet（备选 / 拓展）

- **文献**：[7] Hua Wu, Yan Liu, Yunbai Qin, Haoran You, Zhuoxiang Lin. *RAFnet: SAR Image Autofocusing via Range-Aware Attention and Multi-Scale Loss.* Sensors, 2026, 26(13):4270. DOI: 10.3390/s26134270
- **核心思想**：在渐进式自聚焦框架中嵌入**距离感知注意力（Range‑Aware Attention）**模块：用 1‑D 方位向池化压缩空间特征、从距离维提取高信噪比散射分量，再做轻量跨通道交互，缓解复杂场景下斑点噪声对相位估计的污染。
- **训练损失**：**渐进式多尺度熵损失**——三级级联聚焦器各自带独立损失，权重 0.2 / 0.2 / 1.0（ coarse→fine ）。
- **校正能力**：单级聚焦器纠正最高 2 阶相位误差；三级级联依次纠正 {2,3}、{4,5}、{6,7} 阶，最高可校准 **7 阶**相位失真。
- **速度**：约 **1.73 ms/图**，对比 PGA‑ML 约 163.71 ms。
- **数据**：9 景 ALOS 星载实测回波；散焦由模拟速度估计误差构造。
- **注意**：2026 年新文，需确认代码是否公开、依赖是否可装。

### 2.3 对比表

| 维度 | PAFnet（推荐） | RAFnet |

| 年份 / 出处 | 2022 IEEE TGRS | 2026 Sensors |

## 三、本组选型建议

**首选 PAFnet**：官方代码齐全、无监督易造样本、结构相对简单，最契合课程第 4 周「跑通网络」的节奏。

## 四、输入输出说明（以 PAFnet 为准，待定稿后替换）

- **输入**：`H×W` 复数图像 `I_defocus`（建议训练块 128×128 或 256×256，遵循所选网络约束）。
- **处理流程**：特征提取 → 回归方位相位误差多项式系数 → 方位 FFT → 逐点相位乘子补偿 → IFFT →（逐级重复）。
- **输出**：`H×W` 复数图像 `I_focus`。
- **网络承担的环节**：估计并补偿方位相位误差；「散焦如何由相位误差导致、补偿如何恢复聚焦」是验收时必须能讲清的物理机理。
- **与传统 PGA 的对照**：推理只读取散焦输入；对比「未补偿 / 最小熵自聚焦 / 网络自聚焦」三者的质量与耗时。
