## 1. 项目目标

- 面向 Sentinel‑1 条带模式（Stripmap, SM）数据，构建支持「数据导入 → 算法运行 → 结果对比 → 指标计算 → 导出」的 SAR 图像处理软件。
- 三个可运行模块：RD 成像（MATLAB）、深度自聚焦（Python/PyTorch）、深度旁瓣抑制（Python/PyTorch）。
- 周期 10 周，每人每周 8–10 小时；最终发布 V1.0。

## 2. 模块需求

### 2.1 成像与数据（负责人：____）
- 输入：（仿真回波 / Sentinel‑1 SM SLC 产品）
- 处理步骤：（RD 算法：距离压缩 → 距离徙动校正 → 方位压缩；SLC 读取与参数保存）
- 输出：（复数图像、产品参数 JSON、剖面 PNG）
- 验收条件：（单点/多点定位误差 ≤1 像素；主瓣宽度相对参考偏差 ≤10%；完成 SM SLC 读取与参数保存）

### 2.2 深度自聚焦（负责人：____）
- 输入：散焦复数图像（块 128×128 / 256×256）
- 处理步骤：特征提取 → 回归方位相位误差 → FFT/相位补偿/IFFT（逐级）
- 损失：（图像熵，无监督）
- 输出：聚焦复数图像
- 验收条件：（≥6 个独立非零误差案例，其中 ≥5 个 NRMSE 优于散焦输入；零误差与未见误差补测；与 PGA 对比质量与耗时）

### 2.3 深度旁瓣抑制（负责人：____）
- 输入：复数图像
- 处理步骤：SVFG 生成空间变滤波器 → PSC 并行滤波
- 损失：（MEC 监督）
- 输出：旁瓣抑制复数图像
- 验收条件：（PSLR/ISLR/−3 dB 主瓣宽度达标；强弱双目标检查弱目标保留、幅度偏差、虚假峰）

### 2.4 界面与集成（负责人：____）
- 输入：用户选择入口/方法/参数
- 处理步骤：Streamlit 调用 MATLAB Engine + Python 模块
- 输出：对比图像、剖面、指标 CSV、导出
- 验收条件：方法切换、权重加载、错误输入提示、指定机器复现

## 3. 环境与依赖

- MATLAB（含 MATLAB Engine for Python）
- Python 3.x + PyTorch
- （自聚焦）torchbox、torchsar（PAFnet）
- （旁瓣）SVNN 官方仓库依赖
- Streamlit（GUI）
- 版本管理：Git；结果保存 MAT / PNG / CSV / JSON
